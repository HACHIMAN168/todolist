# 🌸 我的待办清单

简洁、现代的待办事项网页应用，纯 HTML + CSS + JavaScript 实现，无需后端。

## 功能特性

- ➕ 添加任务（回车或点击按钮）
- ✅ 勾选完成 / 取消完成，已完成任务自动分入独立列表
- 🔴🟠🔵 任务优先级（高 / 中 / 低），颜色标识
- ✎ 行内编辑任务内容
- 🗑 清空已完成 / 全部清空（带确认）
- 📊 任务数量统计（总 / 未完成 / 已完成）
- 💾 数据保存在浏览器 localStorage，刷新不丢失
- 📱 响应式设计，手机也能正常使用

## 运行方式

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 技术栈

- HTML5 + CSS3（自定义渐变背景、圆角、阴影、动画）
- 原生 JavaScript（事件委托、localStorage 持久化）
